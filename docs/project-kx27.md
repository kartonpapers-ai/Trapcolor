# Project KX27

Nombre en clave del fork de VectorCraft mantenido en este repositorio, antes presentado como Trap Color.

El nombre visible cambia en la barra de la aplicación, los títulos de ventana, la web, el menú de macOS, Acerca de y los nombres de los workflows. Las traducciones existentes se conservan y reciben alias para los textos nuevos.

Los nombres internos de crates, comandos, preferencias, formatos y rutas de compilación siguen siendo compatibles con VectorCraft. Los créditos, licencias y avisos del proyecto original se conservan. Los enlaces que se identifican como VectorCraft siguen apuntando al proyecto original.

El panel continúa en Window → Trapping. La documentación técnica está en [la guía del módulo](trapcolor-trapping.md).

Para completar el nombre externo, el propietario puede renombrar el repositorio a `project-kx27` desde Settings → General → Repository name. El título de la aplicación cambia mediante el código; la dirección de GitHub Pages depende del nombre real del repositorio. La compilación web usa rutas relativas.

Un nombre en clave no limita el acceso a un repositorio público ni oculta su historial.
